# Chathai Online

ต้นแบบเกมเว็บสไตล์ Ragnarok Online: ตัวละคร 2D บนฉากมุมเฉียง คลิกพื้นเพื่อเดิน เล่นออนไลน์หลายคน

## ไฟล์ในโปรเจกต์ (ชุดเดียว ใช้ได้ทุกที่)

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าเกม วาดภาพทั้งหมดด้วย canvas ไม่มีไฟล์ภาพ |
| `rpg.js` | ระบบ RPG ทั้งหมด: สเตตัส, สายอาชีพ, สกิล, อาวุธ, กระสุน, รีเบิร์ท (ใช้ร่วมกันเซิร์ฟเวอร์/เบราว์เซอร์) |
| `i18n.js` | ภาษา 4 ภาษา (ไทย/English/Tiếng Việt/한국어) แปลข้อความหน้าจอตอนแสดงผล |
| `jobart.js` | หน้าตาชุด/อาวุธ/หมวกของแต่ละอาชีพ (วาดด้วยโค้ด) |
| `world.js` | **โลกทั้งใบ**: 15 แมพ (เมือง 7 + แมพล่ามอน 8), มอนสเตอร์ 73 ตัว, NPC, ร้านค้า, เควสต์ข้างทาง และเควสต์เปลี่ยนอาชีพ 100 เควสต์ |
| `themeart.js` | ภาพของแต่ละธีมแมพ: พื้น, ต้นไม้, ตึก, ของตกแต่ง, ตัวมอนสเตอร์, ฝน/หิมะ/ฟองน้ำ (วาดด้วยโค้ด) |
| `game.js` | แมพ, หาเส้นทาง A*, ผู้เล่น, ตรรกะข้อความ (ใช้ร่วมกันทั้งเซิร์ฟเวอร์และเบราว์เซอร์) |
| `firebase-config.js` | ค่าเชื่อมต่อ Firebase (ใส่ apiKey / appId ตามขั้นตอนด้านล่าง) |
| `online-server.js` | HTTP + WebSocket, เซิร์ฟเวอร์เป็นผู้ตัดสินการเดิน |
| `package.json` | บอกโฮสต์ว่ารันด้วย `npm start` (คือ `node online-server.js`) |
| `manifest.webmanifest`, `sw.js`, `icon-*.png` | ทำให้ติดตั้งเป็นแอปบนมือถือ/Chrome ได้ |
| `vercel.json`, `.vercelignore` | บอก Vercel ให้เสิร์ฟเป็นเว็บธรรมดา ไม่รัน online-server.js |

อัปขึ้น GitHub ทุกไฟล์ในโฟลเดอร์ (รวมไฟล์ที่ขึ้นต้นด้วยจุด เช่น `.vercelignore`) ชุดนี้ชุดเดียวใช้ได้ทั้ง Vercel และโฮสต์ที่รัน Node

## ถ้าต่อเซิร์ฟเวอร์ไม่ได้ เกมเข้าโหมดเดโมเอง

`index.html` พยายามต่อ WebSocket ที่ `/ws` ก่อน ถ้าต่อไม่ได้ (เช่นบน Vercel หรือเปิดไฟล์ตรง ๆ)
จะเข้าโหมดเดโมอัตโนมัติ คนอื่นในหมู่บ้านเป็นบอทจำลอง จึงไม่ต้องมีไฟล์แยกสำหรับเดโม

## วิธีรัน

**ออนไลน์จริง (เครื่องตัวเอง)**

```
node online-server.js
```

เปิด http://localhost:3000 (เปลี่ยนพอร์ตด้วย `PORT=8080 node online-server.js`)
ใช้ Node 18 ขึ้นไป ไม่ต้องติดตั้งแพ็กเกจเพิ่ม
เปิดจากหลายแท็บ หรือหลายเครื่องในวงเดียวกัน (http://IP-เครื่อง:3000) จะเห็นกันและแชทกันได้

**Vercel (ได้โหมดเดโมเท่านั้น)**

Vercel รันเซิร์ฟเวอร์ที่เปิดค้างไว้ไม่ได้ จึงไม่มีออนไลน์จริง นำเข้าโปรเจกต์จาก GitHub ได้เลย
ไม่ต้องตั้งค่า Build Command

**ออนไลน์จริงบนเน็ต**

ใช้โฮสต์ที่รัน Node ค้างได้ เช่น Render, Railway, Fly.io หรือ VPS
ดึงโค้ดจาก GitHub แล้วสั่งรัน `npm start`

- ต้องมี HTTPS ที่ส่งต่อ WebSocket ที่ `/ws` (โฮสต์ส่วนใหญ่ทำให้เอง)
- กำหนด `ALLOWED_ORIGINS=https://โดเมนของคุณ` เพื่อจำกัดว่าเว็บไหนต่อเข้ามาได้
- `/healthz` ใช้เช็คสถานะ

## โลกของ Chathai Online (15 แมพ)

เดินผ่าน "ประตูวาร์ป" ที่ขอบแมพไปแมพถัดไป (ปุ่ม **แผนที่** มุมขวาบนเปิดแผนที่โลก กดเมือง/แมพเพื่อดูข้อมูล แล้วกด "เดินไปที่นี่" ให้ตัวละครเดินข้ามแมพเองได้)

```
หมู่บ้านลำธารไผ่ → ทุ่งไผ่เขียว → โรเซนฮอลล์ ─┬→ ป่าฝนมรกต → หมู่บ้านบ้านต้นไม้อิริน → ตลาดน้ำศรีสยาม → วิหารปะการังใต้ทะเล
                                            └→ มหานครร้างเวลเทอร์ → ทะเลทรายสุริยะ → โอเอซิสสุริยา → นีออนซิตี้ 2099 → ซากโรงงานเหล็กไหม้
                                                                                                   ↓
                                  ดันเจี้ยนเงามืด ← ฟรอสต์โฮล์ม ← ทุ่งหิมะนิรันดร์ ←────────────────┘
```

| เมือง (ปลอดภัย) | ธีม | มีอะไร |
|---|---|---|
| หมู่บ้านลำธารไผ่ | เอเชีย | ร้านยา/ช่างตีเหล็กเริ่มต้น |
| โรเซนฮอลล์ | ยุโรป | **ครูเปลี่ยนอาชีพขั้นแรกทั้ง 5 สาย** สมาคมนักผจญภัย โบสถ์ |
| หมู่บ้านบ้านต้นไม้อิริน | ป่า | ครูคลาส 2 สายนักธนู |
| ตลาดน้ำศรีสยาม | ไทยริมน้ำ | ครูคลาส 2 สายโจร/อโคไลต์ |
| โอเอซิสสุริยา | ทะเลทราย | ครูคลาส 2 สายดาบ/เวท |
| นีออนซิตี้ 2099 | ไซเบอร์พังก์ | ครูคลาส 3 บางสาย (แสงนีออน ฝนตกตลอด) |
| ฟรอสต์โฮล์ม | หิมะ | ครูคลาส 3 บางสาย, **ครูคลาส 4 ทุกสาย**, Holy Knight, Ancient Controller |

แมพล่ามอนสเตอร์ 8 แมพ เลเวล 1–96 (ทุ่งไผ่ 1–5 → ป่าฝน 8–20 → เมืองร้าง 22–32 → วิหารใต้ทะเล 33–42 → ทะเลทราย 41–52 → ซากโรงงาน 54–66 → ทุ่งหิมะ 68–80 → ดันเจี้ยน 82–96)
แต่ละแมพมีมอนสเตอร์ของตัวเอง รวมบอสแมพละ 1 ตัว · มอนสเตอร์บางตัวยิงไกล บางตัวบิน · "วิญญาณคนตาย" ใช้อาวุธและตะโกนชื่อสกิลของผู้เล่นแบบสุ่ม
ข้อมูลมอนสเตอร์ (เลือด/ของที่ดรอป) ดูได้ในแผนที่โลก กดแมพล่ามอน → รายการมอนสเตอร์ → "ไปล่า"

### เควสต์เปลี่ยนอาชีพ
- ทุกการเปลี่ยนอาชีพ (ขั้น 1, 2, 3 และคลาส 4) ต้องทำ **บททดสอบ** ที่ครูของสายนั้นก่อน — **ยกเว้น Solo Player** ที่ไม่ต้องทำ
- เควสต์จะส่งมาที่จดหมายนกพิราบเมื่อเลเวลถึงและอยู่ในสายที่ถูกต้อง · ในหน้า "เลื่อนอาชีพ" จะบอกว่าต้องทำเควสต์ไหนและมีปุ่ม "ไปหาครู" พาเดินไปให้
- เกิดใหม่ (rebirth) จะล้างเควสต์เปลี่ยนอาชีพ ต้องทำใหม่ตอนเปลี่ยนอาชีพรอบใหม่ · GM ข้ามเงื่อนไขนี้ได้
- ทุกเมืองใหม่มีเควสต์ข้างทางเมืองละ 3 เควสต์

### ร้านค้า / ยา / เดินทาง
- ทุกเมืองมีร้านยาและช่างตีเหล็กของตัวเอง ของยิ่งดีเมื่อไปเมืองไกลขึ้น · ยาใหม่: ยาฟื้น MP (น้ำค้าง ฯลฯ) ใช้ได้จากช่องคีย์ลัดเหมือนยาเลือด
- **คาฟร่า** (พนักงานบริการ) อยู่ทุกเมือง แตะที่คาฟร่าแล้วเลือกได้ 3 อย่าง:
  1. **คลังเก็บของ** ฝาก/ถอนของและเหรียญ (สูงสุด 60 ชนิด ผูกกับตัวละคร)
  2. **จุดเกิด** บันทึกว่าตายแล้วจะฟื้นที่เมืองนี้
  3. **เดินทาง** วาร์ปไปเมืองที่เคยไปแล้ว (เสียเหรียญเท่ากับเดินทางด่วนจากแผนที่)
  ต้องยืนใกล้คาฟร่าถึงจะฝาก/ถอน/บันทึกได้ (เช็กที่เซิร์ฟเวอร์) · ข้อมูลคลังอยู่ในไฟล์เซฟของตัวละคร (`storage`)
- ตายแล้วฟื้นที่ **เมืองที่บันทึกจุดเกิดไว้กับคาฟร่า** (ถ้ายังไม่เคยบันทึก = หมู่บ้านลำธารไผ่)
- เมืองที่เคยไปแล้วใช้ "เดินทางด่วน" ได้จากแผนที่โลก (เมื่ออยู่ในเมือง เสียเหรียญ 150 + 15 × เลเวล)
- แตะมอนสเตอร์เพื่อเดินไปตี ตีเองทุก 1 วินาที ถูกตีแล้วมอนสเตอร์จะไล่ ถ้าหนีไกลเกิน 10 ช่องจะกลับที่เดิมและฟื้นเลือด เลือดฟื้นเองเมื่อพ้นการต่อสู้ 5 วินาที
- ธนูใช้ลูกธนู ปืนใช้กระสุน หมดแล้วต้องซื้อเติม
- ปุ่ม **Start** มุมซ้ายล่าง กดแล้วเมนูสไลด์ขึ้น มี สถานะ / สกิล / ถุง / แผนที่ / ตั้งค่า
- ปุ่ม "สถานะ" ดู/เพิ่มสเตตัส, "สกิล" เรียนสกิล (วงกลม = ใช้งาน, สี่เหลี่ยมคม = ติดตัว, สี่เหลี่ยมมน = บัฟ; แตะ 1 ครั้งดูรายละเอียด แตะ 2 ครั้งยกไปวางคีย์ลัด)

### เควสต์ / กล่องจดหมาย / เปลี่ยนอาชีพ
- **นกพิราบ** (มุมซ้ายบน) = เควสต์ใหม่ที่ยังไม่ได้รับ กด "รับเควสต์" ได้เลยไม่ต้องเดินไปหา NPC พอรับแล้วเควสต์จะออกจากนกพิราบไปอยู่ในเมนู **Start › เควสต์**
- เมนูเควสต์มี 2 แท็บ "ภารกิจทั้งหมด" / "ทำเสร็จแล้ว" แต่ละแท็บแบ่ง ภารกิจหลัก · ภารกิจรอง · เลื่อนคลาส (มี (จำนวน) ต่อท้าย) แตะหัวข้อเพื่อขยาย แตะภารกิจเพื่อดูเนื้อหา รางวัลอยู่ด้านล่าง
- **ทำเควสต์เปลี่ยนอาชีพเสร็จ = เปลี่ยนอาชีพให้ทันที** (ต้องกลับไปส่งที่ครูเปลี่ยนอาชีพ) เควสต์เปลี่ยนอาชีพของสายอื่นที่รับไว้จะหายไปเอง · เควสต์คลาส 4 ก็เลื่อนคลาสให้ทันทีเช่นกัน
- **กล่องจดหมาย** (Start › จดหมาย): ทุกครั้งที่เปลี่ยนอาชีพจะมีจดหมายจาก "สมาคมอาชีพ" ส่งชุดอุปกรณ์เริ่มต้นของอาชีพนั้นมา (อาวุธ/มืออีกข้าง/เกราะ + ลูกธนูกระสุนถ้าจำเป็น) กด "รับของ" แล้วไปสวมใส่ในถุง ชุดของแต่ละอาชีพสร้างจาก `RPG.starterKit(job)` ใน `rpg.js`
- **คีย์ลัด**: แตะ 1 ที = ใช้ · แตะ 2 ที = ยกลอย (แตะช่องอื่นเพื่อย้าย/สลับ) · แตะที่ไหนก็ได้นอกคีย์ลัด 1 ที = เอาออกจากคีย์ลัด

### ถ้าจะแก้ / เพิ่มของ
- เลขมอนสเตอร์: ตาราง `MROWS` ใน `world.js` (เลือด/โจมตี/EXP คำนวณจากเลเวลอัตโนมัติ) · หน้าตาดูที่ `MART` (ตระกูล + สี + ลักษณะพิเศษ) · วาดจริงที่ `FAMS` ใน `themeart.js`

- เควสต์เปลี่ยนอาชีพ: `makeJobQuests` · เควสต์ข้างทาง: `SIDE`
- ข้อความของ NPC/เควสต์ใหม่ยังเป็นภาษาไทยอย่างเดียว (ชื่อเมือง/มอนสเตอร์/UI แปลครบ 4 ภาษา; vi/ko ของชื่อมอนสเตอร์ใช้ภาษาอังกฤษ)

## ล็อกอินด้วย Firebase (อีเมล / Google / เกสต์)

เกมใช้ Firebase Authentication (โปรเจกต์ `mygame-88bab`) — วิธีล็อกอินที่เปิดไว้: Email/Password, Google, Anonymous

**ตั้งค่า 1 ครั้ง:** Firebase Console → ไอคอนเฟือง → Project settings → General → "Your apps" → แอปเว็บ (`</>`)
→ SDK setup and configuration → Config → คัดลอก `apiKey` กับ `appId` ไปใส่ในไฟล์ `firebase-config.js` (ค่านี้ไม่ใช่ความลับ)
และตรวจว่า Authentication → Settings → Authorized domains มีโดเมนเกมของคุณ (เช่น `xxx.vercel.app`)

- **สมัคร / เข้าสู่ระบบ**: ใช้อีเมล + รหัสผ่าน (6 ตัวขึ้นไป) · **ลืมรหัสผ่าน**: ส่งลิงก์ตั้งรหัสใหม่ไปที่อีเมล
- **ล็อกอินด้วย Google**: ใช้ได้ทันทีเมื่อใส่ apiKey ถูกต้อง
- **เล่นแบบเกสต์**: ไม่ต้องสมัคร ตัวละครผูกกับเบราว์เซอร์นั้น — ออกจากระบบหรือล้างข้อมูลเบราว์เซอร์แล้วตัวละครหาย
- ถ้า `firebase-config.js` ยังเป็น `PASTE_...` เกมจะใช้ระบบบัญชีสำรองแบบเดิม (ไอดี/รหัสผ่าน/รหัสกู้คืน) ไปก่อน
- **บน Vercel** (ไม่มีเซิร์ฟเวอร์เกม): ล็อกอินจริงผ่าน Firebase แต่ตัวละครและความคืบหน้าเก็บในเครื่อง/เบราว์เซอร์นั้น
- **บนเซิร์ฟเวอร์ออนไลน์** (`node online-server.js`): เซิร์ฟเวอร์ตรวจ ID token ของ Firebase เอง แล้วเก็บตัวละครตามบัญชี
  ตั้ง `FIREBASE_PROJECT_ID` ถ้าใช้โปรเจกต์อื่น (ค่าเริ่มต้น `mygame-88bab`)

## บัญชีสำรอง (ใช้เมื่อยังไม่ได้ตั้งค่า Firebase)

เปิดเกมมาเจอหน้าล็อกอิน: ช่องไอดี + รหัสผ่าน + ปุ่ม **เล่น** ด้านล่างมี **สมัคร**, **ลืมรหัสผ่าน** และ **ล็อกอินด้วย Google**
ล็อกอินแล้วไปหน้า **สร้างตัวละคร** (บัญชีละ 5 ตัว) ครั้งต่อไปจะจำการล็อกอินไว้ และพาไปหน้า "เข้าสู่หมู่บ้าน" เลย

- **ไอดี**: a-z, 0-9, _ ยาว 3-16 ตัว (ไม่สนตัวพิมพ์เล็ก/ใหญ่) · **รหัสผ่าน**: 6-64 ตัว
- **รหัสกู้คืน**: ตอนสมัครเสร็จจะแสดงรหัสรูปแบบ `XXXX-XXXX-XXXX` *ครั้งเดียว* ให้จดไว้ ใช้ที่หน้า "ลืมรหัสผ่าน" (ใส่ไอดี + รหัสกู้คืน + รหัสผ่านใหม่) ใช้แล้วจะได้รหัสใหม่
- **ออนไลน์จริง** (`node online-server.js`): บัญชีเก็บที่ `data/accounts.json` (รหัสผ่านเก็บแบบ scrypt) ความคืบหน้าตัวละคร (เลเวล/ของ/เควสต์) เซฟอัตโนมัติทุก 30 วินาที และตอนออกจากเกม
  ล็อกอินซ้ำจากที่อื่น เครื่องเก่าจะถูกเตะออก · ใส่รหัสผิดเกิน 8 ครั้งต้องรอ 5 นาที
  - เปลี่ยนที่เก็บด้วย `DATA_DIR=/path` — **โฮสต์ที่ดิสก์ไม่ถาวร (เช่น Render แบบฟรี) ข้อมูลจะหายตอนรีสตาร์ท** ต้องต่อ Persistent Disk ไว้ที่ `DATA_DIR`
  - ล็อกอินด้วย Google: สร้าง OAuth Client ID (แบบ Web) ที่ Google Cloud Console ใส่โดเมนเกมใน Authorized JavaScript origins แล้วตั้ง `GOOGLE_CLIENT_ID=...` ที่เซิร์ฟเวอร์ — ถ้าไม่ตั้ง ปุ่ม G จะแจ้งว่ายังไม่เปิดใช้
- **โหมดเดโม** (Vercel/ไฟล์ตรง ๆ): บัญชีและเซฟเก็บในเบราว์เซอร์เครื่องนั้นเท่านั้น ใช้ทดลองได้ แต่ล้างข้อมูลเบราว์เซอร์แล้วหาย และไม่ปลอดภัยเท่าเซิร์ฟเวอร์จริง (ไม่มีล็อกอิน Google)

## ระบบคลาสและอาชีพ

- Class 0 Adventurer → Lv10 เลือก Class 1 (Swordman / Thief / Archer / Magician / Acolyte) → Lv30 เลือกสาย Dharma/Adharma → Lv35 Class 2 → Lv60 Class 3 → Lv80 Class 4 (+1 สกิล) → Lv99 เควสรีเบิร์ท กลับ Lv1 อาชีพเดิม สกิลแรงขึ้น
- Adventurer ยืมสกิลอาชีพอื่นได้ที่ Lv10/30/50/70
- **Solo Player** (คลาสพิเศษ): Adventurer ถึง Lv50 เลือกเป็นได้ ไม่ต้องเลือกฝ่าย Dharma/Adharma · ใช้ดาบคู่ (ใส่ดาบเล่มที่สองที่ช่องมืออีกข้าง ตีเร็วขึ้นและแรงขึ้น) · ถือดาบจะได้ฉายา Black Swordsman · ทุก 10 เลเวล (Lv50/60/70/80/90) ได้สกิลสุ่มจากอาชีพอื่น 1 สกิล ใช้ได้ไม่มีเงื่อนไข · สกิลหลักเน้นความเร็วและดาเมจ
- **Holy Knight** (คลาส 3): Paladin และ Priest ถึง Lv60 เลือกเพิ่มได้ — อาชีพบุก/ป้องกัน/ซัพพอร์ตสมดุล ธาตุแสง
- **Ancient Controller** (คลาส 3): Engineer และ Summoner ถึง Lv60 เลือกเพิ่มได้ — เรียกพลังจากวัตถุโบราณ
- เซฟเก่าที่เป็น Passerby จะถูกแปลงเป็น Solo Player อัตโนมัติ
- สเตตัส STR AGI VIT INT DEX LUK (สูงสุด 99) แต้มสเตตัส/สกิลรีเซ็ตฟรีจนจบ Class 2 หลังจากนั้นเสีย 3000 เหรียญ
- อาวุธใช้ได้ทุกอาชีพถ้าเลเวลและสเตตัสถึง ยกเว้นอาวุธเฉพาะสาย (Katana, Katar, Kunai, Whip, Longbow, Fists, Shoes, Club, Orb glove, Great shield)
- ธนูใช้ลูกธนู ปืนใช้กระสุน หมดแล้วต้องซื้อเติม
- ปุ่ม "สถานะ" ดู/เพิ่มสเตตัส, "สกิล" เรียนสกิล (วงกลม = ใช้งาน, สี่เหลี่ยมคม = ติดตัว, สี่เหลี่ยมมน = บัฟ; แตะ 1 ครั้งดูรายละเอียด แตะ 2 ครั้งยกไปวางคีย์ลัด)
- ตอนนี้ยังไม่มีแมพที่มอนสเตอร์เลเวลสูง ใช้ GM ทดสอบเลเวลสูง

## การควบคุม

- **ซูม**: ใช้สองนิ้วถ่างเข้า/หุบออกบนจอ (คอมพิวเตอร์ใช้ล้อเมาส์)
- **แชท**: ช่องแชทเล็กลงอยู่ข้างปุ่ม Start มีปุ่ม ▾ ซ่อน / 💬 แสดง (จำค่าไว้) · แตะช่องพิมพ์แล้วช่องจะขยายกว้างขึ้นเอง
- **ปุ่มย้อนกลับ** (หรือ Esc): ปิดหน้าต่างที่เปิดอยู่ก่อน ถ้าไม่มีหน้าต่างเปิดจะขึ้นพื้นหลังเบลอพร้อมปุ่ม "เลือกตัวละคร" / "ออกจากเกม" (ออกจะถามว่า "จะไปแล้วจริงๆหรอ" → ใช่ / ยังแค่กดผิด)
- **AUTO** (ปุ่มกลมเหนือจอยสติ๊ก): แตะ 1 ที = เริ่ม ตัวละครจะเดินไปตีมอนสเตอร์ที่ใกล้สุด ปล่อยสกิลที่เรียนแล้ว ต่อบัฟ และกดยาเลือด/MP จากในถุงเอง · แตะอีก 1 ที = หยุด · **กดค้าง** = ตั้งค่า (เปอร์เซ็นต์ที่จะกดยา, เลือกสกิลที่ใช้, ระยะหามอน, หยุดเมื่อเลือดต่ำและยาหมด) ค่าถูกจำไว้ในเครื่อง ออโต้หยุดเองเมื่อ: ตาย, เลือดต่ำและยาหมด, สั่งเดินเอง (จอย/แตะพื้น), ไปคุย NPC · ใช้ได้เฉพาะแมพล่ามอน
- **โจมตีปกติ**: อยู่บนสุดของหน้าต่างสกิล (และวางอยู่ช่อง F1 ให้ครั้งแรก) กดแล้ววิ่งไปตีมอนสเตอร์ที่ใกล้ที่สุด
- **จอยสติ๊ก** มุมขวาล่าง: ลากไปทางไหนตัวละครเดินทางนั้น ปล่อยแล้วหยุด (แตะพื้นเพื่อเดินก็ยังได้)
- **สกิลโจมตี** (ฟันแรง / กวาดวงกว้าง): กดจากช่องคีย์ลัดแล้วตัวละครจะวิ่งไปหามอนสเตอร์ที่ใกล้ที่สุดและใช้สกิลให้เอง
  (แตะพื้นหรือขยับจอยเพื่อยกเลิก) · **ผนึกชีวิต** ใช้ทันที

## ขั้นต่อไปที่แนะนำ

1. ออกแบบสกิลใหม่ (น้อยลงแต่เป็นเอกลักษณ์ + ตะโกนชื่อสกิล/เสียงพากย์)
2. ปรับสมดุลเลือด/ดาเมจของมอนสเตอร์ตามอุปกรณ์จริง
3. ฐานข้อมูลจริง (ตอนนี้เก็บเป็นไฟล์ JSON) และเปลี่ยนรหัสผ่านในเกม
4. ภาพสไปรต์จริงแทนภาพที่วาดด้วยโค้ด

## สกิลนักดาบ (Swordman) ชุดใหม่
แทนสกิลเดิมของ Swordman ทั้งหมด (แต้มสกิลเก่าคืนอัตโนมัติ) — สกิลทุกตัวสืบทอดไปยังอาชีพสายดาบทั้งหมด
- ใช้งาน: **ดาบผ่าซุง I** (ต้องถือดาบ, Lv1), **โล่กระแทก I** (ต้องถือโล่, Lv5) — ตีเดี่ยว
- บัฟ: **ฮึกเหิม I** (Lv9) เพิ่มโจมตี/ป้องกัน/เลือดสูงสุดชั่วคราว
- ติดตัว: **โจมตีต่อเนื่อง** (ตีซ้ำ 5%/เลเวล) → **โจมตีหนัก** (ตายทันที 2%/เลเวล หลังตีซ้ำติด · ไม่ได้ผลกับบอส)
- **ชำนาญดาบ I** (ดาบมือเดียว โจมตี +3%/เลเวล) → **ผู้ใช้ดาบมือเดียว I** (ถือแค่ดาบ ความเร็ว +2%/เลเวล)
- **ชำนาญดาบสองมือ I** (โจมตี +3.5%/เลเวล) · **ชำนาญโล่ I** (ป้องกัน +4%/เลเวล)
- **ชำนาญอาวุธพร้อมรบ I** (ดาบ+โล่ โจมตี/ป้องกัน +2.5%/เลเวล · ต้องมีชำนาญดาบและชำนาญโล่)
- แต่ละสกิลสูงสุด Lv5 · ระบบรองรับเงื่อนไขหลายสกิลก่อนหน้า (`pre` เป็น array)
